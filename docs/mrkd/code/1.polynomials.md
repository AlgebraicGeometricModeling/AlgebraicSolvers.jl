# Polynomials


A convenient function to transform a vector of polynomials into a matrix is the following
```@docs
AlgebraicSolvers.matrixof
```

Vandermonde matrices can also be useful to produce matrices from polynomials and points:
```@docs
AlgebraicSolvers.vdm
```

Here are some additional functions to manipulate polynomials: 
```@docs 
exponent
sparse_pol
```
